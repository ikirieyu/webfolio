# Recommended Case Study Asset Sizes

Gunakan ukuran berikut agar visual konsisten dan tidak mudah terpotong.

## 00-cover

**Recommended:** `1920 × 1080 px` (16:9)

Alternatif ringan: `1600 × 900 px`.

Gunakan untuk cover utama project dan thumbnail showcase. Sisakan safe area sekitar 8–10% dari tepi untuk logo, judul, atau elemen penting.

## Full-width visual

**Recommended:** `1600 × 1000 px` (8:5)

Cocok untuk:
- storefront
- campaign overview
- brand system
- dashboard / desktop UI
- final presentation

## Pair images

**Recommended per image:** `1200 × 1500 px` (4:5)

Contoh nama:

```text
02-pair-01.webp
02-pair-02.webp
```

Kedua gambar sebaiknya punya ukuran dan rasio yang sama.

## Slider / carousel

**Recommended:** `1600 × 1000 px` (8:5)

atau jika seluruh project dominan landscape:

`1920 × 1080 px` (16:9)

Semua file dalam satu slider harus memakai rasio yang sama.

Contoh:

```text
03-slider-01.webp
03-slider-02.webp
03-slider-03.webp
```

## Mobile UI / phone screenshots

Raw screenshot boleh `1080 × 1920 px` (9:16), tetapi sebaiknya dimasukkan ke mockup/canvas 4:5 atau 8:5 sebelum dipakai sebagai visual utama agar presentasinya lebih konsisten.

## Export

Untuk website, utamakan:

- `WEBP` untuk visual raster utama
- kualitas sekitar 80–90%
- usahakan 1 file di bawah ±1–1.5 MB jika memungkinkan
- PNG hanya jika memang butuh transparansi

## Safe area

Untuk `00-cover`, jangan taruh teks atau logo penting terlalu dekat tepi. Gunakan safe area sekitar **10%** dari setiap sisi karena thumbnail homepage dan layout responsive bisa memberi padding berbeda.
